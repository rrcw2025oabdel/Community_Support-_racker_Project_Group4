##  Style Guide

We decided as a group that the color and typography will be similar to Pixel River graphic identity. 

### **Primary Color**
**Hex / RGB:** `#313886`

### **Secondary Color**
**Hex / RGB:** `#67AADC`

### **Header Color**
**Hex / RGB:** `#575E9F`

### **Footer Color**
**Hex / RGB:** `#878CB6`

### **Background Color**
**Hex / RGB:** `#E5E8EA` or `#BBC6D7`

---

## Typography

### **Primary Font**
**Name / Size / Weight:** Inter / 16px / Regular

### **Secondary Font**
**Name / Size / Weight:** Inter / 14px / Medium

### **Headings (H1–H3)**
- **H1:** 32px, Bold, `#313886`
- **H2:** 26px, Semibold, `#575E9F`
- **H3:** 20px, Medium, `#575E9F`

### **Body Text**
**Size / Line Spacing / Color:** 16px / 1.6em / `#1A1A1A` (dark gray)

---

## UI Elements

### **Buttons – Default**
**Shape / Size / Color:** Rounded 6–8px / Medium / Background `#313886`, Text white

### **Buttons – Hover**
**Hover Color / Animation / Shadow:** Background `#575E9F`, 150ms transition, small shadow

### **Links – Default**
**Color / Underline:** `#313886`, no underline

### **Links – Hover**
**Hover Color / Underline / Effect:** `#575E9F`, underline appears on hover

### **Icons / Images**
**Style / Dimensions:** Outline-style icons, 24–32px

---

## Layout

### **Alignment / Spacing**
Top-left or centered layout with spacing between 24–32px
